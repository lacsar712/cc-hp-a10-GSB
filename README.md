# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 夜间禁写窗

- 炮制员在顶栏「夜间禁写」页配置每天禁止开炒的时间段（闭区间，开始晚于结束表示跨零点，如 22:00 至次日 06:00），保存后立即生效。
- 服务端按服务器时钟判定：落在禁写窗内的写入一律拒绝并注明处于禁写窗，同时追加一条禁写流水；窗外正常写入。
- 质检员可查看时间段配置、当前是否禁写与禁写流水，不可修改配置（接口同样拒绝）。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. processor 在「夜间禁写」页把禁写时间段改成覆盖当前服务器时间，再写白芍 → 拒绝并提示处于禁写窗，禁写流水新增一条。
5. 把禁写时间段挪开（不覆盖当前服务器时间），再写白芍 → 写入成功。
6. checker 登录后可在「夜间禁写」页看到时间段配置与禁写流水，但没有保存按钮，直接调接口改配置返回 403。
