# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 夜间禁写窗

炮制员可在顶栏「夜间禁写」专页配置每天禁止开炒的时间段（默认 22:00~06:00，按服务器时钟判定，时区由 `CURFEW_TZ` 控制，默认 Asia/Shanghai）。落在禁写闭区间内的写入一律被拒并写明处于禁写窗，同时追加一条禁写流水；窗外正常写入。调整时间段保存后立即生效。质检员可查看时间段配置与禁写流水，但不可改配置。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 顶栏进「夜间禁写」：炮制员把禁写时间段改成覆盖当前服务器时间，保存后立即生效；回到记录页再写白芍被拒，提示处于夜间禁写窗，禁写流水新增一条。
5. 把时间段挪开（不覆盖当前时间）后再写白芍成功。
6. checker 登录后可在「夜间禁写」页查看时间段配置与禁写流水，但没有编辑入口（直接调 PUT /api/curfew 同样被 403 拒绝）。
